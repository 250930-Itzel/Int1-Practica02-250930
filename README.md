## Comandos Básicos paa Maquetado de la Documentación utilizando el estandar de Markdown(.md)
---
Makdown es el estándar utilizado pr Git y GitHub, para estilizar (maquetar) la documentación del proyecto entender el contecxto y operación del mismo

## 1.Encabezados o Titulos (HEADERS)

Para poder utilizar una buena documentación del proyecto debemos distribuir correctamente los contenidos, para poder delimtar o hacer énfasis (enfatizar), es decir resaltar los secciones más importantes, podernos utilizar lo siguente:

**EJEMPLOS:**

# Encabezado de Nivel 1
## Encabezado de Nivel 2
### Encabezado de Nivel 3
#### Encabezado de Nivel 4
##### Encabezado de Nivel 5
###### Encabezado de Nivel 6
####### Encabezado de Nivel 7- El estandar solo permite 6 niveles para títulos,a partir del séptimo será presentado como texto plano (sin estilo)
